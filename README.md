# Evan Simpson's Portfolio

Personal portfolio site hosted via GitHub Pages at [educatorsRlearners.github.io](https://educatorsrlearners.github.io/portfolio.github.io/).

A three-page site — Home, Projects, and Writing & Talks — no build step, no framework, just HTML and CSS.


## Structure

- `index.html` — home page: nav, hero (intro + photo + contact links), About, and Skills sections.
- `projects.html` — Projects page.
- `writing.html` — Writing & Talks page.
- `style.css` — all styling shared across the three pages, including the responsive breakpoint at `860px` (which also switches the nav to a mobile menu).
- `evan_simpson_cv.pdf` — the CV linked from the page; keep both in sync when updating.
- `images/` — site images, including the hero photo.
